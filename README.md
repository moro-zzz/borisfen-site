# Борисфен — авіамодельний клуб, Київ

Статичний сайт клубу: HTML + CSS, без збірки.

- Продакшн: https://borisfen-site.vercel.app
- Хостинг: Vercel, проєкт `borisfen/borisfen-site`, автодеплой з гілки `main`.
- Лого у векторі: `img/logo-dark.svg`, `img/logo-light.svg`, `img/logo-mark.svg`.

## Локальний перегляд

```powershell
python -m http.server 8766
```

і відкрити http://localhost:8766.
